# Mission AUDIO (numpy/scipy) — effets sonores + musiques synthétisés

Dossier à toi : `assets/audio/`, `tools/audio/`. Sortie : SFX en `.wav` (44,1 kHz, 16 bit, mono sauf ambiances en stéréo, normalisés ~-3 dBFS, pas de clic début/fin), musiques en `.ogg` (ffmpeg disponible : `/opt/homebrew/bin/ffmpeg -c:a libvorbis -q:a 6`), + `assets/audio/manifest.json` listant chaque fichier (nom, durée, boucle oui/non, catégorie, tags). Toutes générées par code (synthèse additive/FM/soustractive, bruit filtré, enveloppes, réverbération par convolution d'une réponse impulsionnelle synthétique, delay, saturation douce, stéréo large). Qualité visée : propre, punchy, non agressive, façon jeu AAA stylisé (pas de bips de 8-bit sauf UI discrète). Chaque famille de sons doit avoir 2–4 variantes (suffixe _1, _2, _3…), pitch/timbre légèrement différents (le jeu choisit au hasard).
