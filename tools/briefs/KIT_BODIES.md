# Mission KIT_BODIES (Blender) — corps modulaires + équipements (têtes, torses, épaules, dos)

Dossier à toi : `assets/models/kit/`, `tools/blender_kit_bodies/`.
Lis impérativement `data/kit_contract.json` (repère, pivots, masque de couleur de sommets, liste exhaustive de pièces). Style : héros trapus « chibi héroïque » (≈3,3 têtes), grosses mains/pieds lisibles de loin, gros volumes, bevels propres (modificateur Bevel + normales lissées / edge-split à 30°), subdiv léger quand pertinent, 800–3000 triangles par pièce corporelle, ≤ 2500 par pièce d'équipement. Palette peinte par masque de couleurs de sommets (voir contrat) : une seule matière `M_Kit` (Principled, base color = COLOR_0 attribut couleur) — le jeu remplace le matériau par un shader toon qui lit R/G/B/A comme masque (R primaire, G secondaire, B accent/métal, reste = peau, A = AO). **Exporte l'attribut couleur (export_vertex_color / export_active_vertex_color_when_no_material selon l'API Blender 5.2 — vérifie par relecture du GLB, COLOR_0 doit exister).**

## Livrables
* `assets/models/kit/kit_bodies.glb` : pour chacune des 7 espèces (human, orc, goblin, minotaur, skeleton, beast, demon) les 7 pièces `body_<espèce>_<torso|pelvis|head|arm_l|arm_r|leg_l|leg_r>` (origines sur les pivots du contrat). Tous les corps partagent exactement le même squelette (pivots). Différences : human = proportions héroïques ; orc = carrure large, mâchoire à défenses, peau = « skin » ; goblin = tête immense + grandes oreilles pointues, membres fins (le jeu le met à l'échelle 0,8) ; minotaur = tête de taureau avec cornes, cou épais, sabots (échelle jeu 1,35) ; skeleton = os (peau = couleur os), orbites lumineuses (B = accent) ; beast = loup-garou/panthère bipède, museau, oreilles, griffes, fourrure (peau = pelage) ; demon = cornes, peau rouge/anthracite, yeux brillants. La peau est la couleur « base » (masque 0,0,0) pour pouvoir être teintée.
* `assets/models/kit/kit_gear.glb` : toutes les pièces de `hats`, `torso_gear`, `torso_gear_skirts`, `shoulders` (_l/_r), `backs` du contrat, avec les noms exacts. Les pièces d'équipement épousent la silhouette de base *human* ; elles doivent aussi aller correctement sur orc (±15 % de carrure), goblin et minotaur. Les cheveux/chapeaux ne doivent pas intersecter le crâne de façon visible.
* `assets/models/kit/kit_bodies_manifest.json` : liste des pièces avec triangles et notes ; `assets/models/kit/preview/` : planches contact PNG (par espèce, vue de face + 3/4 dos, puis planches équipement) rendues en EEVEE avec un matériau test qui colore selon le masque (primaire=rouge sombre, secondaire=bleu, accent=or, peau=beige) pour qu'on juge la qualité.
