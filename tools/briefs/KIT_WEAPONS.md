# Mission KIT_WEAPONS (Blender) — armes, boucliers, invocations, props

Dossier à toi : `assets/models/kit/` (fichiers `kit_weapons.glb`, `kit_props.glb`, manifests, `preview_weapons/`), `tools/blender_kit_weapons/`.
Lis impérativement `data/kit_contract.json` (orientations des armes, masque de couleur de sommets, liste exhaustive de pièces). Même style que le kit de corps (travaillé en parallèle par un autre agent) : héroïque, trapu, gros volumes lisibles à distance, bevels propres, bords de lame un peu épaissis, 200–1800 triangles par arme. Couleurs via masque de sommets COLOR_0 : R = matériau principal (bois/cuir/manche/tissu), G = secondaire (métal sombre/bord), B = accent (lame brillante/or/gemme/cristal, zones émissives), A = AO. Une matière `M_Kit` unique (Principled lisant l'attribut couleur) ; vérifie que COLOR_0 est bien exporté dans le GLB (relis le fichier).
Grandeur : une arme de poing standard fait ~0,9–1,1 m (épée longue 1,05 m, grande épée 1,35 m, hallebarde 2,1 m, arc long 1,5 m, bâton 1,6–1,9 m). Les armes appariées (griffes, poings/gants, palettes de défibrillateur) sont livrées en `wpn_<nom>_l` et `wpn_<nom>_r` (symétriques). Les boucliers : disque/écu, plan XY, face vers +Z. Les poings/griffes englobent la main (gants de lutteur, gantelets, griffes d'éclair).
* `kit_weapons.glb` : toutes les pièces `weapons` du contrat (noms exacts ; origine = prise en main).
* `kit_props.glb` : `summons_props` du contrat (invocations : sanglier, loup, chauve-souris, tourelles, totems, feu follet/wisp, mannequin d'illusion ; pièges, mine, pierre tombale, coffre fermé + couvercle séparé `prop_chest_lid` (origine = charnière), coupe trophée, tas de pièces, support bannière, mannequin d'entraînement, râtelier d'armes, cristaux, brasero, tonneau, caisse). Origine de chaque prop au sol (y=0) sauf mention.
* Planches contact `preview_weapons/*.png` + `kit_weapons_manifest.json` (nom, triangles, longueur, remarques).
